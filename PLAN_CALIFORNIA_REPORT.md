## PHASE 2 — THE VIDEO SCRIPT (5–10 min, ~1,100–1,500 words)
Arc (California story, hypothesis-neutral): 
1. **Cold open** — 1908, Orange County: the government-ordered dip that killed six cattle
   (Levengood/Joplin chain, all sourced).
2. **The program** — 1907 CA law; the USDA formula (8 lb white arsenic/500 gal); quarantine maps;
   ~50–150 vats statewide; ended in OC March 1912.
3. **The chemistry** — arsenic is an element; it does not decay; per-vat ~100–500 lb model estimate.
4. **The contrast (the user's core beat):** the **Southeast/Florida program was government-run —
   state crews built and OPERATED the vats, and the sites were LOGGED** (Florida 3,000+ vats known;
   NSW Australia later built a register + buyer notification). **California relied on individual
   ranches** to build and run their own vats per a mailed federal circular — **no agency ever
   recorded where they were.** When dipping ended, the locations ended with it.
5. **The decades of silence** — no follow-up in the 30s–90s; Phase-I practice reaches ~1950 aerials;
   dipping ended 1912 → structurally invisible.
6. **The areas** — Ladera (built on the range; reviews were paper-only; arsenic never tested), Coto
   (the documented ranch: part built over, home place still open ground), the statewide map.
7. **The wrong-arsenic problem** — where CA did test (orchard sites/schools), it tested the
   lead-arsenate signature, never the dip signature.
8. **The resolver** — one soil test on documented ground; approved-language close + disclaimer.
Deliverable: `media/video/SCRIPT_california.md` with per-beat B-roll callouts + on-screen source
citations. Tone rules: measured, archival, no fear cues.
