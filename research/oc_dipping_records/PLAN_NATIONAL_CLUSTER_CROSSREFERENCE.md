# Plan: nationwide cross-reference — rare-cancer clusters × dipping-era ranch land
*Drafted 2026-08-10. A screening methodology, not an epidemiological study. Everything this
produces is a CANDIDATE list for soil testing and registry-grade analysis — never a causal claim.*

## The question, stated neutrally
Across the 15 dipping-program states: where were communities developed on or beside former
ranch/range land, and did any of them report rare-cancer clusters (with emphasis on Ewing
sarcoma and other pediatric solid tumors) **within ~20 years of development** — the window
our forward-cohort model identifies for in-utero/early-childhood exposure during construction?

## Honest priors (write them down before looking)
1. Ewing sarcoma has NO established environmental cause; ~200–250 US cases/year; its rarity
   makes true clusters statistically fragile. Finding ES near former ranch land is EXPECTED
   occasionally by chance because ranch land is where suburbs get built in the Sunbelt.
2. Cluster reports are noisy: reporting bias, boundary-drawing (the "Texas sharpshooter"
   problem), and media amplification all inflate apparent patterns.
3. Therefore the output of this cross-reference is a RANKED CANDIDATE LIST scored on
   *independently verifiable* criteria — never a "map of arsenic cancers."
4. A null result (no excess pattern) is publishable and valuable, and we commit in advance
   to reporting it.

## Phase 1 — Build the exposure-side layer (desk, 2–4 weeks)
1. **Program footprint at county level** (A1): digitize quarantine county lists from the
   USDA circulars/proclamations we hold + annual BAI reports (HathiTrust/archive.org) into
   a county-year table, 1906–1943.
2. **Ranch-to-suburb conversion inventory**: for each program state (starting CA, then TX),
   list master-planned communities and large subdivisions built on former ranch/range land,
   with development years. Sources: county planning archives, developer histories, USGS
   historical topo/imagery (the LEHRP method, scaled). Priority: communities with
   >1,000 homes built within 10 years on land that was open range in the program era.
3. **Dip-site likelihood scoring** per community (the LEHRP targeting method): herd-scale
   documentation, water/drainage convergence, historical structures on early imagery,
   county enforcement intensity (heavy-tier counties in the circulars score higher).

## Phase 2 — Build the outcome-side layer (desk, parallel)
1. **Documented cluster investigations** (A2/B1): state health department cluster reports,
   ATSDR petitions and responses, CDC/state registry SIR analyses. These are public,
   citable, and pre-adjudicated — start here, not with news.
2. **Published literature** (B1): PubMed sweep — pediatric cancer clusters, Ewing sarcoma
   geography/SES/rurality studies, arsenic-cancer literature (noting arsenic's established
   cancers are skin/bladder/lung — a bone-tumor link is NOT established; log this).
3. **News-reported clusters** (B2, flagged as unverified): systematic sweep of reputable
   outlets for "cancer cluster" + community names from Phase 1. Never case-level detail;
   aggregate counts only; no family identification, ever (project Rule 3 applies nationwide).
4. **Registry data requests** (the national G01): state registries publish county/tract
   SIRs; where a Phase-1 community shows a Phase-2 signal, request standard aggregate
   statistics through official channels.

## Phase 3 — The cross-reference
Join the layers on geography + time: for each candidate community, record
(a) dip-likelihood score, (b) development window, (c) any cluster report and its grade,
(d) lag between development and report, (e) whether ANY soil arsenic data exists.
Score and rank. Known starting candidates to adjudicate honestly:
- **Ladera Ranch, CA** — our case; the template.
- **The Acreage, FL (2010, pediatric brain tumors, FDOH-declared)** — former ranch/ag land,
  registry-confirmed cluster, in the ONE state with a vat inventory to check against. If
  Florida's vat map and its cluster investigations have never been overlaid, that overlay
  is the single highest-value analysis in this plan — the state's own data can test the
  method end-to-end.
- Others emerge from Phase 2; do not pre-name them.

## Phase 4 — Outputs
1. National map: program counties × conversion communities × graded cluster reports.
2. Ranked candidate table with full provenance and grades.
3. A methods write-up honest enough to survive peer review — because if this pattern is
   real anywhere, the evidence that convinces the world will be soil measurements at
   candidates this screen selected, not the screen itself.

## Ethics & discipline (non-negotiable, inherited from LEHRP rules)
Aggregate data only; no identification of individuals or families; no "cluster maps" without
statistical support; every claim graded; nulls reported; the Texas-sharpshooter critique
addressed explicitly in methods (exposure layer is built BLIND to outcome locations —
Phase 1 completes before Phase 2 joins).

## Feasibility note
Phases 1–3 are desk-executable with the tools already proven in LEHRP (imagery pipelines,
records requests, registries). Realistic effort: CA+TX+FL first pass in weeks, full 15-state
pass in months. Florida first for the method validation (it has the answer key); California
first for the mission.
