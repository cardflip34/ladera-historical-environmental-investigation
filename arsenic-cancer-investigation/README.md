## Bottom line
Arsenic→Ewing causation is **currently unsupported/unestablished** (no etiologic literature; the only
arsenic–Ewing science is arsenic-as-therapy; MOA/tissue mismatch). The environmental predicate is
**plausible but unmeasured locally**. Path forward = **measurement** (soil speciation, biomarker
reconstruction, blinded tumor analysis, preregistered epidemiology) — gated per the execution plan.
