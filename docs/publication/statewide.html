Statewide screening · companion to the Ladera Ranch investigation

The General Case, and the archive behind it

Eleven California communities were run through the same documentary pipeline as Ladera Ranch, and a parallel hunt located every rights-clean historical image of the ranches underneath them. This page holds the map, the ranking, and the pictures.

11 communities screened 5 counties 2 never reviewed at all 60 images located 26 photographs · 27 maps · 7 other 0 dip vats visible in any image
No community named on this page is asserted, implied, or found to be contaminated. The only measured soil fact anywhere in this program is “unstudied.” What is ranked below is where an unanswered question is widest — never where any risk is higher. The single fact that would answer it, for any community, is a direct soil arsenic test, which has been run for none of them.

Where the dipping program and modern development overlap

The 1907–1915 USDA cattle-tick program covered essentially all of developed Southern California. This is a context map of that county-level footprint against the communities built on former ranchos — not a map of dip vats (their locations were never inventoried) and not a map of contamination.

Every row shares two facts: no cattle-dip vat is named to any of the eleven ranches, and no soil arsenic test exists for the dip question at any of them. “No vat named” is an absence of a located record — bounded by archive-access limits during the run — never proof of absence.

The archive — every image located, by ranch

A parallel hunt searched Calisphere, the Online Archive of California, the Bancroft, Huntington, USC, the Library of Congress, and David Rumsey by owner family and photographer — the way these collections are actually catalogued. Only clearly public-domain or openly-licensed items were downloaded; each tile shows repository, date, and rights. Tap any image to read its full provenance. None depicts a cattle-dip vat — the working-facility context the Ladera record lacked, but not the vat itself.
