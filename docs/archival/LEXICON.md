## How to use this list on a new document

1. **Check the document has a text layer before trusting a zero result.**
   Extract the text and divide characters by pages. Under about 200 characters per page
   means the document is an image scan and your search is returning nothing because
   there is nothing to search, not because the term is absent.
   The 136-page Ladera Planned Community Program Text returned **135 characters across
   136 pages** and had passed every prior keyword search silently.

2. **OCR it if needed.** On macOS, render pages at 200 dpi and run the Vision text
   recogniser; no external OCR install is required.

3. **Run all 159 terms, not just the correct names.** Register A is a control group.
   The informative result lives in registers B through G.

4. **Read every non-zero hit in context.** In the 2026 sweep, all 26 hits on concrete
   vocabulary were at industrial facilities, never on open ranch land. The count alone
   would have been misleading.

5. **Discard abbreviation collisions.** `REC` matched twice as the land-use abbreviation
   for *recreation*, not as an ASTM Recognised Environmental Condition.
