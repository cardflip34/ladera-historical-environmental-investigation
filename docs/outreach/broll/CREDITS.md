# B-roll provenance and rights

Every clip and image used in the video must be traceable to a source. This file records that.

## Archival film — public domain

**`USDA_1922_MollieOfPineGroveVat_reel1_PUBLICDOMAIN.mp4`**
- **Title:** *Mollie of Pine Grove Vat* (1922)
- **Producer:** U.S. Department of Agriculture (National Archives, Record Group 33, Extension Service)
- **Subject:** Cattle fever tick eradication and arsenical dipping — the same federal program,
  same era, and same practice documented in this investigation. (Filmed in the South, not
  California — see the honesty note below.)
- **Source:** Internet Archive, item `33-198-r-1` — https://archive.org/details/33-198-r-1
- **Rights:** **Public Domain** (Creative Commons Public Domain Mark 1.0; U.S. Government work).
  Free to use, including commercially, no permission required.
- **Other reels:** `33-198-r1.mp4`, `33-198-r2.mp4`, `33-198-r3.mp4` at the same item.

**On-screen credit to use when this footage appears:**
> Archival footage: *Mollie of Pine Grove Vat*, U.S. Department of Agriculture, 1922. Public domain, via the National Archives / Internet Archive.

### Honesty note — do not skip this
This film shows **Southern** cattle dipping, not Orange County. It is authentic footage of the
**same USDA program and the same arsenical dipping practice** described in the report, which is
why it is legitimate B-roll for explaining *what dipping was*. It is **not** footage of this land.
When it is on screen, the narration should be describing the practice in general ("this is what
cattle dipping looked like"), never implying it was shot here. Label it as 1922 archival footage.

## What NOT to use
- The YouTube clip "1960s Agriculture: African Cattle Pesticide Dip" — **rejected.** Wrong
  subject (African cattle, 1960s, modern pesticide — not 1900s California arsenical tick dip) and
  unverified/likely-owned rights. Using it would be both inaccurate and a copyright exposure.
