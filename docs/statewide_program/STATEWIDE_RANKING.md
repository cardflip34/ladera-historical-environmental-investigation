## What every row shares

- **No cattle-dip vat is named** to any of the 11 ranches.
- **No soil arsenic test exists** for the dip question at any of them.
- Newspaper/primary confirmation was **bounded by tooling limits** this run (CDNC and Library of Congress returned 403/404 to automated queries), so every "no vat" is an *absence of a located record*, never proof of absence.


## The two findings that stand out

- **Two communities were never reviewed at all.** Rancho Bernardo and the Rancho Santa Fe / Del Mar / Solana Beach area were master-planned and built *before CEQA existed*, so no historical-aerial review of the ranch land was ever required — a wider gap than Ladera's.
- **Newhall / Santa Clarita is a partial counter-example.** The 2013 Regional Water Board required arsenic + DDT soil testing of historically-farmed parcels there. That targeted orchard/row-crop chemistry, not dip vats — but it shows the system *can* catch arsenic when the trigger is right.


## Bottom line

Eleven communities across five counties, every one with the same structural review gap, two never reviewed at all. The Ladera gap is the **general case**. This is a prioritisation of *where an open question is widest* — not a finding about any place. The single fact that would turn any of these open questions into an answer is a soil test that has been run for none of them.
