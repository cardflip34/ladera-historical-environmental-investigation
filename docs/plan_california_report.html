The California Report — phased plan

Converting the 288-page Ladera investigation into a condensed, area-based California report, then a 5–10 minute video script, then the full B-roll package.

LEHRP · plan of record · July 2026 · supersedes the Ladera-centric structure

Discipline gates apply to every phase: hypothesis-neutral · A1–D source grade on every claim · counter-evidence mandatory · no residential addresses or coordinates · aggregate health data only · confidence badges · no sensationalism · standard disclaimer on every section and in the video description. No contamination is asserted anywhere; no California dip-site soil has ever been tested.

Phase 1 — The California Report

1.1 Frame & section order

One statewide story: a state-mandated arsenical cattle-dipping program (1907 → Orange County federally released March 1912 — now dated from the primary press), never inventoried, never marked, never follow-up tested — examined area by area:

  1. LADERA RANCH — priority area
  2. BELL CANYON / COTO DE CAZA — the documented Joplin dip ranch (1909 patent = NE Coto, partly built over; 1938 ranchstead in Bell Canyon on still-open ground)
  3. Newport Coast · 4. Irvine · 5. Eastbluff / Back Bay / Santa Ana Heights
  4. Statewide tier — one spread per probability-map community: San Juan Capistrano, Yorba Linda, Anaheim Hills, Long Beach (Los Cerritos — documented; Los Alamitos), Camp Pendleton, Simi Valley, Fillmore, Rancho Santa Fe/Del Mar, Rancho Bernardo, Rancho Peñasquitos, Rancho Cucamonga, Jurupa Valley, Valencia/Santa Clarita, Tejon, Miller & Lux
  5. Program history (1907 law · USDA 8-lb formula · quarantine geography · the March-1912 releases)
  6. What other places did (Florida/SE-US government-run & logged · NSW register) · 9. Arsenic mass-balance model · 10. Methods & sources

1.6 The condense pass USER DIRECTIVE

Shorter despite the statewide scope — target ~120–150 pages (from 288):

  • One methods chapter; boilerplate/disclaimer collapsed to a footer line + once per section
  • Merge duplicative framework chapters into one tight intro; delete recap and process narration — findings + sources only
  • Area cap ~6–10 pp (priority areas ≤15), figure-led; tables replace prose lists
  • Kill weak/duplicate figures — strongest visual per point

1.7 Output format USER DIRECTIVE

(a) HTML broken down by section — an index page + one cross-linked HTML page per area/section, each self-contained with its figures; (b) a separate single PDF of the whole condensed report. Every migrated claim keeps its source_id; new claims (quarantine lift, Levengood ID, GLO patent, EnviroStor/GeoTracker first-hand reads) registered in sources.csv first.

Phase 2 — The video script (5–10 min, ~1,100–1,500 words)

  1. Cold open — 1908, Orange County: the county-ordered dip that killed six of Levengood's cattle; herd bought from Joplin of Bell Canyon (all primary-press sourced)
  2. The program — 1907 law; 8 lb white arsenic / 500 gal; quarantine maps; ~50–150 vats; OC released March 1912
  3. The chemistry — arsenic is an element, it does not decay; ~100–500 lb per heavily-used vat MODEL EST.
  4. The contrast (core beat) — Florida/SE: government-run, state crews built and operated the vats, sites logged (Florida 3,000+ known; NSW later built a register + buyer notification). California: each ranch built and ran its own vat from a mailed federal circular — no agency ever recorded a single location
  5. The decades of silence — no follow-up in the 30s–90s; Phase-I practice reaches ~1950 aerials; dipping ended 1912 → structurally invisible to every later review
  6. The areas — Ladera (built on the range; paper-only reviews; arsenic never tested) · Coto/Bell Canyon (the documented ranch: part built over, home place still open ground) · the statewide map
  7. The wrong-arsenic problem — where CA did test, it tested the orchard (lead-arsenate) signature, never the dip signature
  8. The resolver — one soil test on documented ground; approved-language close + disclaimer

Deliverable: media/video/SCRIPT_california.md with per-beat B-roll callouts and on-screen citations. Tone: measured, archival — no fear cues, no music stings on health claims.
