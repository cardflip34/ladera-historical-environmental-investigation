# THE NEXT TASK — generate the six local appendices

**Why this and nothing else:** the priority-1 request letter is written but **cannot be sent
without its attachments.** Those six appendices are the single hard blocker on the entire
records-led Mission 6 sequence. Every one of the 11 registry requests depends on the same tract /
address / AOI / crosswalk backbone. Producing it once unblocks all of them. It is also pure
desk work on data already in the repo — no authorization, no agency, no cost, no gate to pass.

**Deliverables** (into `data/development/mission6_appendices/`, generated by a committed script,
not hand-typed):

| # | Appendix | Content | Notes |
|---|---|---|---|
| A | Canonical tract list | 123 tracts + all aliases | must state the TR 17588 include/exclude decision explicitly |
| B | Address/APN crosswalk | deduplicated for agency production | derive from the 6,446 matched address points |
| C | Project AOI | polygon + rendered map | reuse the existing AOI definition; do not invent a new boundary |
| D | Street-to-tract crosswalk | from the 288-feature road index | **preserve the 3 multi-date tracts as multiple rows** |
| E | Known identifiers | permit, case, agreement, Board item, document IDs | harvest from Mission 4/5 evidence |
| F | Party name variants | developer, builder, HOA, utility, agency grantor/grantee | needed so the County's name-search doesn't miss records |

**Hard rules carried forward — do not violate:**
1. **Do not collapse the three multi-date tract sources** (TR 15615, TR 16116, TR 16121) into a
   single completion date without a documented, written rule.
2. **Preserve the TR 17588 conflict.** The 2024 Board-certified index says Ladera Ranch; the live
   FeatureServer says Rancho Mission Viejo. Keep both, and exclude from Ladera counts unless the
   canonical crosswalk independently includes it.
3. **A road acceptance, map recordation, sales date, year-built value, school opening, or aerial
   observation is NOT a certificate of occupancy.** Never let one substitute for one.
4. Every appendix row carries provenance back to a source in the manifests.

**Definition of done:** all six appendices generated by a reproducible script, verification suite
passes, and `MISSION_6_REQUEST_01_OC_PERMITS_DRAFT.md` has its "blocking prerequisites" section
checked off — leaving the request awaiting only the user's authorization to send.
