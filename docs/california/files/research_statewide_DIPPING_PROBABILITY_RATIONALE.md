# California dipping-probability map — rubric & per-ranch rationale

> **GRADED INFERENCE, not measurement.** This ranks the **probability that arsenical cattle-dipping
> occurred** on/near a ranch in 1907–1915 — the *practice*, not contamination. Only the DOCUMENTED tier
> is a fact; the rest are inference from quarantine-county intensity + documented cattle operations.
> **NOT a contamination map** (no soil tested anywhere), **NOT a map of vat locations** (unknown), and
> the practice occurring does **not** imply residue, exposure, or harm. Map:
> `CA_dipping_probability_map.jpg`.

## Rubric

| Tier | Criteria |
|---|---|
| **DOCUMENTED — arsenical** | A source names *arsenical* cattle dipping at/near the ranch (fact). |
| **DOCUMENTED — chem. unconfirmed** | Dipping named, but chemistry not stated (may be lime-sulfur, not arsenic). |
| **HIGHLY PROBABLE** | Heavily-infested quarantine county + large documented cattle operation under the compulsory 1907 arsenical-dip law → dipping almost certainly occurred, even if no vat is located. |
| **LIKELY** | Heavily-infested quarantine county + documented cattle range. |
| **PLAUSIBLE** | Lesser-infested county + cattle range, OR a competing arsenic vector (orchard lead-arsenate) that better explains any arsenic. |
| *green ring* | Land now **federal / farmland / unbuilt** — not under housing (context, not a community). |

Quarantine tiers are USDA Circular 174 (1911): **heavy** = San Diego, Orange, Ventura, Santa Barbara,
San Luis Obispo, Fresno; **lesser** = Los Angeles, Riverside, San Bernardino, Kern, Tulare, Kings, Madera.

## Notes on Long Beach (per the request)
Long Beach spans **two** Nieto-grant ranchos: **Rancho Los Cerritos (#5)** — the one place with a
*documented* dipping photograph, though of **sheep** and with **chemistry unstated** (so it sits in the
"documented, arsenic-unconfirmed" tier, not the arsenical-fact tier) — and **Rancho Los Alamitos (#14)**,
a Bixby cattle ranch in the lesser-infested LA county (plausible). Both are shown.

## What would move a ranch up a tier
A **named arsenical dip record** (e.g., a county-veterinarian vat list) promotes an inference tier to
DOCUMENTED; a **soil arsenic test** is the only thing that speaks to residue — and none has been run
anywhere. The tiers are a *research-prioritisation*, not a statement about any community.
