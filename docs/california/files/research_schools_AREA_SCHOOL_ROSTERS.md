# Verified School Rosters — Study-Area Communities

**Purpose:** roster of every school (public, charter, private, preschool–12) verified as *physically located* in each area, for environmental-history cross-referencing.
**Compiled:** 2026-07-21 (all sources retrieved this date via live web verification).
**Scope note:** community names only (no street addresses beyond what identifies the community, per project privacy rules). Schools that *serve* an area but sit outside it are listed in footnotes, not tables.

**Source grades** (per project registry): A1 official machine-readable gov dataset (NCES CCD/PSS, CDE open-date records as relayed through NCES/Ed-Data) · A2 official gov/district/school/city webpage · B1 research-institution or transparent-methodology directory (PrivateSchoolReview/Niche republishing NCES PSS private-school survey data) · B2 reputable secondary (Wikipedia, Yelp-confirmed operating status, aggregator listings) · C unverified.

**DTSC EnviroStor column:** envirostor.dtsc.ca.gov was **bot-gated on 2026-07-21** (HTTP 403 on `https://www.envirostor.dtsc.ca.gov/public/profile_report?global_id=30020004`; no CAPTCHA attempted per protocol). Except where a known entry was supplied to this task (Oso Grande School, EnviroStor ID 30020004; Esencia K-8, Rancho Mission Viejo), every cell reads "Gated — not checked." **This is a data gap, not a "no."** The CDE School Directory (cde.ca.gov/SchoolDirectory) was also bot-gated (Radware redirect) for city-level queries after two successful fetches; NCES, Ed-Data, district, and school sites were used instead.
